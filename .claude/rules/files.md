# ファイル（R2）のルール

- ファイルは R2 の非公開バケットに `{世帯ID}/{UUID}` で保存する。元のファイル名をパスや URL に使わない
- 閲覧は有効期限 60 秒の署名付き URL のみ。公開 URL は作らない
- 画像はクライアント側で JPEG に再エンコードしてから送る（EXIF の位置情報を残さない）
- サーバー側でも形式（中身のシグネチャ）とサイズを検証する。拡張子や Content-Type だけを信用しない
- 元のファイル名はログ・エラーメッセージに出さない
