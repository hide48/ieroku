保証期限の計算（純関数）

// src/lib/date.ts（日付はここだけ。Date は使わない。ブラウザ組み込みの Temporal には頼らない）
import { Temporal } from "temporal-polyfill";
export const todayJst = (): string => Temporal.Now.plainDateISO("Asia/Tokyo").toString();

// src/lib/warranty.ts
/** 開始日 + months か月 − 1 日。add は月末を自動で丸める。例: 2024-02-29 + 12 → 2025-02-28 → 2025-02-27 */
export function calcExpiresOn(startsOn: string, months: number): string {
  return Temporal.PlainDate.from(startsOn).add({ months }).subtract({ days: 1 }).toString();
}
// テスト: 2026-04-01+12→2027-03-31 / 2026-01-31+1→2026-02-27 / 2024-02-29+12→2025-02-27 / 2026-03-01+1→2026-03-31

特に見てほしい点

1. 期限計算の規則（月単位で持ち、+N か月の前日。2/29・月末の丸め）が保証書の感覚と合っているか。
2. 通知メールの本文に品名を書いてよいか（ADR 0015 提案）。
3. ファイル配信を R2 の S3 署名付き URL ではなく Worker 経由の HMAC URL にする判断（ADR 0016 提案）。
4. PR の分割（土台 → 部屋・種類 → 家電と保証 → 一覧・処分 → 添付 → 通知）の粒度。
5. HouseholdScope をブランド型にして、サーバー関数の入力から作れないようにする形。
