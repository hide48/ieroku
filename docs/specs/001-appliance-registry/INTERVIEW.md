# 001 家電登録 — ヒアリング結果（2026-11-26）

claude.ai でのインタビュー結果。`/spec` で SPEC.md と design.html を作るときの入力として使う。
未決事項は `/spec` のインタビューで追加確認すること。

## 目的

MVP（実際に使い始められる最小限の機能）として、家電・住宅設備・家具を登録し、保証期限を管理できるようにする。

## 決定事項

| 論点           | 決定                                                                                        |
| -------------- | ------------------------------------------------------------------------------------------- |
| 対象           | 家電 + 住宅設備（給湯器・エアコン・食洗機など）+ 家具                                       |
| 保証のないもの | 登録できる。その場合のみ保証期限は任意                                                      |
| 必須項目       | 品名・メーカー・型番・購入日・保証期限                                                      |
| 追加項目       | 購入店・購入金額、延長保証の情報、設置場所（部屋）、保証書・レシートの写真                  |
| 保証期限の入力 | 購入日 + 保証年数で自動計算し、手で修正もできる                                             |
| 延長保証       | 1 件の家電に複数記録できる（メーカー保証 + 店舗の延長保証など。保証ごとに期限・通知を管理） |
| 部屋           | 先に部屋を登録して選ぶ方式（表記揺れを防ぎ、後の間取り機能につなげる）                      |
| 処分・買い替え | 「処分済み」にして履歴を残す。一覧からは隠れ、通知も止まる                                  |
| 一覧の機能     | 保証期限が近い順 / 部屋ごと / 種類ごと / キーワード検索（品名・メーカー・型番）             |
| 添付ファイル   | 写真と PDF を複数。1 件あたり最大 10 ファイル、1 ファイル 10MB まで                         |
| 期限通知       | MVP に含める。メールで 30 日前・7 日前                                                      |
| 通知の宛先     | 人ごとに受信の有無を設定できる                                                              |
| 編集権限       | 夫婦どちらも全件を編集・処分済みにできる。誰がいつ変更したかは記録する                      |

## 前提（ADR より）

- 利用者は夫婦 2 人（1 人は Android、もう 1 人は iPhone）。スマホでの利用が中心
- すべてのデータに世帯 ID を持たせ、`src/server/data/` 経由でのみアクセスする（0002）
- ファイルは R2 の非公開バケットに `{世帯ID}/{UUID}` で保存し、閲覧は 60 秒の署名付き URL
- 画像はクライアント側で JPEG に再エンコードして EXIF（位置情報）を除去する
- 日付は `<input type="date">`、フォームは TanStack Form + Zod（0008）
- 項目は将来の AI 解析（0012）の出力と同じ形にしておく
- 通知は Cron Triggers で毎日チェックし、同じ通知を二重に送らない

## /spec で追加確認したい論点

- 家具など型番がないものの扱い（型番を必須から外すか）
- 保証期限の計算規則（例: 「購入日から 1 年」の期限日を、1 年後の前日とするか当日とするか）
- 保証の開始日が購入日と異なる場合（設置日・引き渡し日起算の住宅設備など）
- 通知メールを送る時刻と、送信できなかったときの扱い
- 期限切れの保証の表示方法
- 部屋の登録・並べ替え・削除（家電が紐づいている部屋を消す場合）
- 処分済みからの復元を許すか
- 実装の分割案（部屋 → 家電と保証 → 添付ファイル → 通知 の順に PR を分けるなど）
