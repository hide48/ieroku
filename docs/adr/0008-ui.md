# 0008 UI は shadcn/ui（Base UI）+ Tailwind

- 状態: 承認済み（2026-11-26）

## 背景

夫婦がスマホ（Android と iPhone）で使う。日付の入力が多い（購入日・保証期限）。依存は少なくしたい。

## 決定

- shadcn/ui を使い、土台は Base UI（2026 年 7 月からのデフォルト）。スタイルは Tailwind CSS
- 部品はリポジトリにコピーされるため、追加された部品は PR で中身を確認する
- `shadcn add` は依存をインストールするため、**部品の追加はひでの承認制**（0004）
- 日付はブラウザ標準の `<input type="date">` を使う（スマホのネイティブのピッカーが出る）
- フォームは TanStack Form + Zod。Zod のスキーマはサーバー側の検証と共有する
- アイコンは lucide、フォントは system-ui（Web フォントは読み込まない）

## 検討した代替案

- Radix（shadcn の旧デフォルト）: 新規で選ぶ理由が薄い
- React Aria: 日付部品が充実しているが記述が冗長。PC での日付入力に不満が出たら日付部品だけ検討する
- Mantine などの完成品ライブラリ: コードを所有できず、依存が大きい

## 影響

- Base UI には日付部品がないが、標準入力で代替する

## 見直す条件

- 標準の日付入力では使い勝手が足りない
