# 0012 AI 解析は Workers AI を基本、必ず人が確認してから保存

- 状態: 承認済み（2026-11-26）／実装は第 2 弾

## 背景

保証書・レシート・契約書の画像や PDF、商品ページの URL から登録項目を自動で埋めたい。資料には個人情報が含まれる。

## 決定

- 画像・PDF は Workers AI の `toMarkdown`（OCR 含む）と画像対応モデルで解析する。URL のページは Browser Run で取得する
- AI には決まった JSON の形で項目（品名・型番・購入日・保証期間・購入店・金額など）だけを返させる
- 解析は「AI で読み取る」ボタンを押したときだけ行う（アップロードしたものを自動で AI に送らない）
- AI の結果は**下書きとして表示し、人が確認してから保存する**。AI は DB に直接書き込まない（読み取りミスと、URL 先の文章による指示の乗っ取りへの対策）
- 家電保証の入力項目は、MVP の時点から AI の出力と同じ形で定義しておく

## 検討した代替案

- AI Gateway 経由で Claude を使う: 日本語のレシート・手書きの精度が足りない場合に検討する。その場合データが Anthropic に渡るため、外部に送ってよいデータのルールを別途決める

## 影響

- Workers AI は顧客データを学習に使わず、通常の推論では入出力を保持しない方針
- 費用は 1 日 10,000 Neurons までの無料枠に収まる見込み

## 見直す条件

- 実際のレシート・保証書での読み取り精度が実用に足りない
- 無料枠を継続的に超える
