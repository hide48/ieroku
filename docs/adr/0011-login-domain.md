# 0011 ログイン方法とドメイン

- 状態: 承認済み（2026-11-26）

## 背景

妻は iPhone（Face ID）、ひでは Android（指紋認証）。スマホで手軽に、かつ安全にログインしたい。PWA のインストール情報や通知の登録はドメインに紐づく。

## 決定

### ログイン（Cloudflare Access）

- **パスキーを基本**、メールのワンタイムコードを予備（機種変更・紛失時用）にする
- 許可するのは夫婦 2 人のメールアドレスのみ。Access のポリシーは Terraform で管理する
- ワンタイムコードの安全性はメールアカウント次第のため、2 人ともメールアカウントの 2 段階認証を必須にする
- セッションの保持期間は 7 日程度

### ドメイン

- 独自ドメインを Cloudflare Registrar で取得する（DNS・Access・Workers を同じ場所で Terraform 管理）
- 苗字や地名など、名前や住所が推測できるドメイン名は避ける。登録者情報は非公開
- 本番は `app.<ドメイン>` のみで公開し、本番の `workers.dev` は無効にする
- プレビューは `workers.dev` の URL を Access で保護して使う

## 検討した代替案

- Google ログイン: 外部サービスへの依存が増える
- `workers.dev` のまま運用: 後からドメインを変えると PWA や通知の登録をやり直す必要がある。通知メールの送信元にも独自ドメインが必要になる見込み

## 影響

- ドメイン費用（`.com` で年 1,500〜2,000 円程度）

## 見直す条件

- Access のパスキー機能（2026 年 11 月追加）に問題がある
