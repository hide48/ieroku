# 0003 認証は Cloudflare Access + アプリ側の JWT 検証

- 状態: 承認済み（2026-11-26）

## 背景

利用者は夫婦 2 人だけ。個人情報を扱うため、許可された人以外はアプリに到達すらできないようにしたい。認証ライブラリを入れると依存が増える。

## 決定

- アプリ全体の手前に Cloudflare Access を置き、許可した 2 人のメールアドレスだけを通す（Free プランは 50 ユーザーまで無料）
- アプリ側は Access が付与する JWT（`Cf-Access-Jwt-Assertion`）を、チームドメインの公開鍵と AUD タグで検証し、メールアドレスから利用者と世帯を特定する
- ローカル開発では Access がないため `DEV_AUTH_EMAIL` でログイン済みとみなす。**`APP_ENV=production` でこの値が設定されていたら起動時にエラーで停止する**（テストで担保）
- ログイン方法の詳細は 0011

## 検討した代替案

- Better Auth / Supabase Auth: アプリ内で認証を実装する必要があり、依存とコードが増える

## 影響

- 認証ライブラリが不要
- JWT 検証の実装を誤ると認証をすり抜けられるため、検証処理には単体テストを必須にする

## 見直す条件

- 利用者が世帯外に広がる（例: 親族と共有する）
