# 0004 サプライチェーン対策

- 状態: 承認済み（2026-11-26）

## 背景

2026 年は npm のサプライチェーン攻撃が相次いだ（3 月の axios、5 月の TanStack 42 パッケージなど）。TanStack の件では、AI エージェントの設定ファイル（`.claude/settings.json`）に居座る手口も報告された。多くは公開から数十分〜数日で検知されている。

## 決定

- パッケージマネージャーは pnpm 11
  - `minimumReleaseAge: 10080`（公開から 7 日経つまでインストールしない）
  - 依存のインストールスクリプトはデフォルトでブロックし、必要なものだけ `pnpm approve-builds` で承認、承認リストをコミットしてレビューする
  - CI では lockfile を固定してインストールする（frozen lockfile）
- **依存パッケージの追加は人間だけが行う**。Claude は理由とコマンドを提示する（`pnpm add` / `dlx` / `npx` / `shadcn add` は拒否ルール）
- 依存の更新は Dependabot（cooldown 7 日、週 1 回まとめて 1 PR）
- GitHub Actions の Action はコミットハッシュで固定し、権限は既定で読み取り専用、`pull_request_target` は使わない
- 外部から取り込むスキル（modern-web-guidance など）は特定のコミットをコピーし、更新時は差分をレビューする
- `.claude/` 配下の変更は人間のレビュー必須（フックで Claude の編集をブロック）
- gitleaks をコミット前と CI で実行する

## 影響

- 新しいバージョンの取り込みが最大 7 日遅れる。セキュリティ修正が急ぎの場合は個別に判断する

## 見直す条件

- 待機期間を超えて検知されない攻撃が主流になった
